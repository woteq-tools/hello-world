# Hello World

A minimal GitHub Pages site.

- **Live site:** <https://woteq-tools.github.io/hello-world/>
- **Source:** <https://github.com/woteq-tools/hello-world>

## Publishing

The site is published from the `main` branch, at the repository root.

```bash
git clone git@github.com:woteq-tools/hello-world.git
cd hello-world
# edit index.html
git commit -am "Update site"
git push origin main
```

Pages settings live at
[Settings → Pages](https://github.com/woteq-tools/hello-world/settings/pages)
with source **Deploy from a branch** → `main` / `/ (root)`.
